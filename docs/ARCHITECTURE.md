# 🏗️ `InsightUIUX™` Architecture (`:4023 /api/uiux`)

## 1. Mission & Boundary
`InsightUIUX™` encapsulates the 111 chapters of `Book_Lit_Master_UI_UX_Engineering.md` and `.agents/skills/ux-engine/SKILL.md` into a deterministic 2D UI/UX Design System microservice (`:4023`):
- **Anti-AI-Slop Linter**: Rejects pure `#000000` backgrounds and decorative purple-to-blue gradients.
- **Concentric Border Radius Calculator**: Enforces $R_{\text{outer}} = R_{\text{inner}} + \text{padding}$.
- **7-Decision Mathematical Typography**: `1.25` modular scale (`12px`, `15px`, `19px`, `24px`, `30px`), weights `400`/`600`, `68ch` reading measure, and `tabular-nums`.
- **4-State Reactive Machine & Form UX**: Verifies `onBlur` -> `onChange` validation timing and persistent `<label for="...">` above inputs.
